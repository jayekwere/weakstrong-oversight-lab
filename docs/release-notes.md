# WeakStrong Oversight Lab v0.1.0
A functional local research system, public synthetic benchmark, reproducible demonstration and accessible research dashboard. No API key or paid service is required. This release makes no claims about frontier-model safety or real-world operational effectiveness.

See [methodology](methodology.md), [observed results](results.md), [reproduction](reproduction.md), and [security](../SECURITY.md). External adapters are transport-tested, not live-model evaluated. The release is intended for reproducible experimentation; adapting it to real data or live agent tools requires a separate threat model.
