    - Independently installable Python >=3.12 package, locked runtime and development dependencies.
    - At least 120 validated synthetic cases; no oracle labels in model observations.
    - Development/held-out separation, fixed seed, dataset fingerprint and saved actual output.
    - Working CLI, local API, distinct responsive dashboard, functional filters and exports.
    - Unit, integration, security-negative, adapter, API and CLI checks; core coverage >=85%.
    - Ruff, strict type checks, Bandit, dependency audit, secret scan, wheel and container build.
    - No external model calls without explicit opt-in and request/token/spend limits.
    - Clean reproduction, actual browser screenshots, successful GitHub Actions and public initial release.
    - All results identify simulation status; no claim of real-model performance without a run.
